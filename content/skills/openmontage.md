# OpenMontage

Первая открытая агентная система видеопроизводства.  
Репозиторий: [calesthio/OpenMontage](https://github.com/calesthio/OpenMontage)  
Лицензия: AGPL-3.0 | ⭐ 16.4k

> Превращает AI-ассистента в полноценную видеостудию. Опиши что хочешь — агент сам исследует тему, пишет сценарий, генерирует ассеты, монтирует и рендерит финальное видео.

---

## Быстрый старт

### Требования

- Python 3.10+
- FFmpeg (`brew install ffmpeg` / `sudo apt install ffmpeg`)
- Node.js 18+
- AI-ассистент (Claude Code, Cursor, Copilot, Windsurf, Codex)

### Установка

```bash
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup
```

Если нет `make`:
```bash
pip install -r requirements.txt && cd remotion-composer && npm install && cd .. && pip install piper-tts && cp .env.example .env
```

### Запуск

Открой проект в AI-ассистенте и опиши что хочешь:

```
"Сделай 60-секундный анимационный explainer о том, как работают нейросети"
"Создай документальный монтаж о ночном городе. Только реальные съёмки, без закадрового текста"
"Сними рекламный тизер для продукта AquaPulse"
```

## Что доступно без API-ключей (бесплатно)

| Возможность | Инструмент | Описание |
|------------|-----------|---------|
| Озвучка | Piper TTS | Офлайн TTS, звучит как человек |
| Видеоматериал | Archive.org, NASA, Wikimedia | Бесплатные архивные и документальные съёмки |
| Стоковые фото/видео | Pexels, Unsplash, Pixabay | Бесплатные ключи разработчика |
| Композиция (React) | Remotion | Анимации, субтитры, графики, TalkingHead |
| Композиция (HTML) | HyperFrames | Кинетическая типографика, GSAP-анимации, SVG-персонажи |
| Пост-продакшн | FFmpeg | Кодирование, субтитры, микширование |

**Два бесплатных пути:**
- **На основе изображений:** Piper озвучивает, изображения дают визуал, Remotion анимирует
- **Реальные съёмки:** Документальный монтаж из Archive.org, NASA, Wikimedia без видеогенерации

## Работа с референсом

Можно начать с видео, которое уже нравится:

```
"Вот YouTube-шорт, который мне нравится. Сделай что-то похожее, но о CRISPR для старшеклассников."
"Проанализируй этот Reel и дай мне 3 оригинальных варианта для моего продуктового запуска."
"Мне нравится темп и хук в этом видео. Сохрани эту энергию, но сделай 45-секундный explainer о чёрных дырах."
```

Агент анализирует транскрипт, темп, сцены, кадры и стиль, а затем предлагает дифференцированные концепции с оценкой стоимости.

## Контроль качества

- **Pre-compose validation** — блокирует рендер при нарушении delivery promise (например, "motion-led" видео с 80% статичных изображений)
- **Post-render self-review** — ffprobe, извлечение кадров, анализ аудио, проверка субтитров. Если тест провален — видео не показывается
- **Slideshow risk scoring** — 6-мерный анализ, предотвращающий "анимированный PowerPoint"
- **Бюджетный контроль** — оценка стоимости до выполнения, резервирование, лимиты ($10 по умолчанию, настраивается)
- **Audit trail** — каждое решение логируется с альтернативами и confidence score

## Структура проекта

```
tools/              # 52 Python-инструмента
  video/            # 13 инструментов видеогенерации
  audio/            # 4 TTS-провайдера + музыка
  graphics/         # 9 инструментов генерации изображений
  enhancement/      # Апскейл, удаление фона, улучшение лиц
  analysis/         # Транскрипция, детекция сцен, анализ кадров
  subtitle/         # Генерация SRT/VTT
pipeline_defs/      # YAML-манифесты пайплайнов
skills/             # Markdown-скиллы (знания агента)
  pipelines/        # Директорские скиллы по стадиям

  core/             # Базовые инструментальные скиллы
schemas/            # 15 JSON Schema для валидации
```
